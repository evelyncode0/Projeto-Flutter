📚 Catálogo Pessoal de Cursos

Projeto desenvolvido como parte dos estudos do curso de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de praticar o desenvolvimento de aplicações mobile utilizando Dart e Flutter.

O projeto consiste em um aplicativo de catálogo pessoal de cursos, permitindo ao usuário organizar e acompanhar os cursos que deseja conhecer, está realizando ou já concluiu.

🎯 Objetivo

O principal objetivo do projeto é colocar em prática conceitos de desenvolvimento mobile utilizando Flutter e Dart, explorando a construção de interfaces, organização do código, gerenciamento de dados e implementação de funcionalidades comuns em aplicações mobile.

O projeto possui caráter educacional, sendo desenvolvido para aprendizado e aplicação dos conhecimentos adquiridos durante a graduação.

✨ Funcionalidades

O aplicativo permite:

📚 Cadastrar novos cursos;

✏️ Editar cursos existentes;

🔎 Visualizar os detalhes de um curso;

⭐ Marcar cursos como favoritos;

📌 Acompanhar o status dos cursos;

✅ Marcar cursos como Concluído;

📖 Marcar cursos como Em andamento;

👀 Marcar cursos como Quero conhecer;

📋 Visualizar e organizar o catálogo pessoal de cursos.

🛠️ Tecnologias utilizadas

Dart — linguagem de programação utilizada no desenvolvimento;

Flutter — framework utilizado para desenvolvimento da aplicação mobile.

🚀 Como executar o projeto
Pré-requisitos

Antes de executar o projeto, é necessário ter o ambiente Flutter configurado na máquina.

Também é necessário possuir um dispositivo Android conectado ou um emulador configurado para executar a aplicação.

1. Clonar o repositório

Clone o projeto utilizando o Git:

git clone <URL_DO_REPOSITORIO>


Esse comando cria uma cópia do projeto em sua máquina.

2. Acessar a pasta do projeto

Entre no diretório do projeto:

cd catalogo_pessoal


O comando cd é utilizado para acessar a pasta onde estão os arquivos do projeto.

3. Instalar as dependências

Execute:

flutter pub get


Esse comando verifica o arquivo pubspec.yaml e instala/resolve as dependências necessárias para executar o projeto.

Esse passo é importante principalmente após clonar o projeto ou quando houver alterações nas dependências utilizadas pela aplicação.

4. Executar os testes

Para executar os testes automatizados do projeto:

flutter test


Esse comando verifica os testes implementados e informa se foram executados com sucesso ou se existem falhas.

5. Executar o aplicativo

Para executar o aplicativo em um dispositivo ou emulador:

flutter run


O Flutter irá compilar a aplicação e executá-la no dispositivo selecionado.

6. Gerar o APK

Para gerar o arquivo APK da aplicação Android:

flutter build apk


Após a compilação, o arquivo APK será gerado no diretório:

build/app/outputs/flutter-apk/
